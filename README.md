# 🦁 Bit - The Bitbucket CLI Tool

> *powered by gopu.inc*

![Version](https://img.shields.io/badge/version-1.0.2-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)
![Platform](https://img.shields.io/badge/platform-linux%20%7C%20macos%20%7C%20windows-lightgrey.svg)

**Bit** est un outil en ligne de commande (CLI) ultra-léger écrit en C, conçu pour simplifier votre workflow Bitbucket. Il remplace les commandes Git complexes par des commandes intuitives et rapides.

---

## 🚀 Fonctionnalités

* **Syntaxe Simplifiée** : Oubliez les commandes à rallonge.
* **Multi-OS** : Binaires optimisés pour Linux (x64/x86), ARM, Windows et MacOS.
* **Suggestions Intelligentes** : Détecte vos fautes de frappe et suggère la bonne commande.
* **Super Rapide** : Compilé avec des optimisations de haut niveau (`-O3`).
* **Léger** : Aucune dépendance lourde, binaire de ~16 KB.

---

## 📦 Installation (v1.0.2)

### Installation rapide (Linux / Alpine)
Utilisez notre script d'installation automatique qui détecte votre architecture :
```bash
curl -sSL [https://raw.githubusercontent.com/ton-pseudo/bit/main/install.sh](https://raw.githubusercontent.com/ton-pseudo/bit/main/install.sh) | sh
```
### Installation manuelle
**Téléchargez l'archive correspondant à votre système depuis la page Releases :**
1. **Extrayez l'archive** : tar -xzvf bit-linux_x64-v1.0.2.tar.gz
2. **Déplacez le binaire** : sudo mv bit /usr/local/bin/
3. **Vérifiez l'installation** : bit version
